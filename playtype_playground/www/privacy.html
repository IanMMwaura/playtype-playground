Privacy

Effective August 28, 2026

Dashboard activity

The app uses your filter choices and player selections to update the charts. Shared links may include those choices in the URL. No account is required.

NBA data

The included CSV contains NBA playtype statistics collected through nba_api. Normal dashboard use reads that local file. Refreshing the file sends requests to NBA Stats from the machine running the refresh command.

Server logs

A hosting provider may keep standard request logs, including timestamps, requested paths, browser information, and IP addresses. The provider controls how long those logs are kept.

Cookies

Shiny may use temporary session data while the dashboard is open. This project does not include advertising cookies or behavioral tracking.

Contact

Questions about this deployment can be directed to the repository maintainer.
